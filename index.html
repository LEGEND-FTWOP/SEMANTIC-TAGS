About Me

Background, Core Values & Technical Competencies

My Background

I am a front-end web developer with over 5 years of experience crafting accessible, performance-oriented websites. My journey began when I noticed how often standard web interfaces fail users who rely on assistive technologies like screen readers, speech-recognition software, or keyboard-only navigation.

Rather than treating accessibility as a cosmetic patch or an afterthought, I center every project around native HTML5 semantics. Clean, valid markup naturally provides screen readers with navigational landmarks, heading structures, and predictable tab orders.

Design System

1. Accessible UI Component Kit

A collection of reusable, unstyled user interface components engineered strictly against the W3C WAI-ARIA Authoring Practices Guide (APG) featuring modal dialogs, tab panels, and keyboard focus trapping.

  • Focus Trapping: Prevents focus escape in dialogs.
  • Focus Restoration: Returns focus to trigger on close.
  • Roving Tabindex: Keyboard arrow navigation.
Web Performance

2. EcoMetrics — Green Web Audit

A lightweight benchmarking tool analyzing page payload, server carbon emissions, and Core Web Vitals with high-contrast accessibility-compliant data visualizations.

  • Data Tables: Backed by semantic <table> markup.
  • High Contrast: Contrast ratio exceeding 9:1.
  • Motion Safety: Respects reduced motion preferences.
Developer Tools

3. DevFlow — Documentation Engine

Static documentation interface built for keyboard power users, with automatic heading hierarchies, in-page landmark skips, and semantic <kbd> shortcuts.

  • Keyboard Shortcuts: J / K section cycling.
  • Skip Anchors: Quick jump to code examples.
